Domain and Range — Graphically

College Algebra  ·  §3.1b  ·  Christopher Halverson  ·  Fall 2026  ·  STUDENT

You're looking at the graph of a function — no equation, just the picture. How would you figure out which x-values and which y-values the function uses? What would you look for on the graph to decide?
Domain from a Graph

Domain = all x-values where the graph exists.

To find it: scan the graph left → right. Identify the leftmost and rightmost x-values the graph reaches.

Domain: [−3, 3]
Dashed lines project the endpoints down to the x-axis
Range from a Graph

Range = all y-values the graph reaches.

To find it: scan the graph bottom ↑ top. Identify the lowest and highest y-values the graph reaches.

Range: [−1, 2]
Dashed lines project the endpoints left to the y-axis
Endpoint Guide
 Filled dot — endpoint included → use [ or ] Open circle — endpoint excluded → use ( or ) Arrow — continues to ±∞ → write inf
Worked Examples
Example 1  —  Segment — both endpoints closed
State the domain and range.
Scan left–right: x goes from −3 to 4, both filled dots.
Domain: [−3, 4]
Scan bottom–top: y goes from −1 to 2, both filled.
Range: [−1, 2]
Example 2  —  Segment — left endpoint open
State the domain and range.
Left dot is open ⇒ x = −3 is excluded.
Domain: (−3, 4]
Open at (−3, 2) ⇒ y = 2 excluded; closed at (4, −1) ⇒ included.
Range: [−1, 2)
Example 3  —  Ray going right — infinite domain
State the domain and range.
Closed dot at x = −2 (included); arrow means continues forever right.
Domain: [−2, ∞)
Lowest y-value is −2 (at the start); ray rises without bound.
Range: [−2, ∞)
Example 4  —  Parabola segment — closed endpoints
This graph shows $y = x^2 - 4$ from $x = -2$ to $x = 2$. State the domain and range.
Scan left–right: x from −2 to 2, both closed.
Domain: [−2, 2]
Lowest point is the vertex at (0, −4); endpoints are at y = 0.
Range: [−4, 0]
