Inputs and Outputs

College Algebra  ·  §3.1  ·  Christopher Halverson  ·  Fall 2026  ·  INSTRUCTOR

Think of a function like a vending machine: you put in a code (input) and get out a snack (output). If $f(x) = 13$, what is the question actually asking — are you finding the output or the input?
Definition

Definition. A function $f$ is a rule that assigns to each input value exactly one output value. If $x$ is the input, then $f(x)$ (read “$f$ of $x$”) is the output. The pair $\bigl(x,\; f(x)\bigr)$ is called an input-output pair.

The same function can be represented three ways. All three describe identical input-output pairs — they are not different functions, just different views of the same relationship:

RepresentationWhat it showsExample: $f(x)=2x+1$
FormulaA rule to compute $f(x)$ for any input$f(x) = 2x + 1$
TableSpecific input-output pairs listed in rowsRow $(2, 5)$ means $f(2)=5$
GraphEvery pair $(x, f(x))$ plotted as a pointPoint $(2, 5)$ is on the graph

The connection: every row in a table is a point on the graph, and every point on the graph can be computed from the formula. To evaluate ($x \to f(x)$): use the formula, look up a table row, or read up from the graph. To reverse ($f(x) \to x$): solve the equation, scan the table’s output column, or read across from the graph.

Evaluating: Input → Output

$f(x)$ means: substitute the value for every $x$.

e.g. $f(x) = 3x + 4$, find $f(5)$:
$f(5) = 3(5) + 4 = 19$

e.g. $g(x) = x^2 - 2x + 1$, find $g(4)$:
$g(4) = 16 - 8 + 1 = 9$

Tip: replace every $x$ with the input, then simplify using order of operations.

Reversing: Output → Input

Given $f(x) = k$, set the formula equal to $k$ and solve for $x$.

e.g. $f(x) = 4x - 3$, if $f(x) = 17$, find $x$:
$4x - 3 = 17 \Rightarrow 4x = 20 \Rightarrow x = 5$

e.g. $h(x) = 2x^2 + x$, find $h(-3)$:
$2(9) + (-3) = 18 - 3 = 15$

Tip: plug in a negative carefully — use parentheses around the input.

From a Graph

Every point on the graph is $(x,\, f(x))$. To evaluate: go to $x$ on the horizontal axis, trace up to the graph, read the $y$-value. To reverse: go to $y = k$ on the vertical axis, trace across to the graph, read the $x$-value.

Gold lines show: trace from $x=2$ up to the line, then left to $y=5$, giving $f(2)=5$.
Worked Examples
Example 1  —  Evaluate a linear function
Let $f(x) = 3x + 4$. Find $f(5)$.
$f(5) = 3(5) + 4 = 15 + 4 = 19$
Example 2  —  Evaluate a quadratic function
Let $g(x) = x^2 - 2x + 1$. Find $g(4)$.
$g(4) = 16 - 8 + 1 = 9$
Example 3  —  Reverse: find the input
Let $f(x) = 4x - 3$. If $f(x) = 17$, find $x$.
$4x - 3 = 17 \Rightarrow 4x = 20 \Rightarrow x = 5$
Example 4  —  Evaluate with a negative input
Let $h(x) = 2x^2 + x$. Find $h(-3)$.
$h(-3) = 2(-3)^2 + (-3) = 2(9) - 3 = 18 - 3 = 15$
Example 5  —  Read from a table

Use the table to answer: (a) What is $g(-1)$?   (b) For what $x$ does $g(x) = 6$?

$x$$g(x)$

(a) Find the row where $x = -1$: $g(-1) = 2$.

(b) Find rows where $g(x) = 6$: $x = -2$ and $x = 2$. Two inputs share one output — this function is not one-to-one.

Example 6  —  Read from a graph

Use the graph of $f(x) = x + 2$ to find:
(a) $f(3)$   (b) For what $x$ does $f(x) = 1$?

(a) Gold crosshairs: trace from $x = 3$ up to the line → point $(3, 5)$, so $f(3) = 5$.

(b) Red point: trace from $y = 1$ across to the line → point $(-1, 1)$, so $f(x) = 1$ when $x = -1$.

Practice Problems
1.
Let $f(x) = 5x - 2$. Find $f(3)$.
$f(3) = 13$
2.
Let $g(x) = x^2 + 1$. Find $g(-2)$.
$g(-2) = 4 + 1 = 5$
3.
Let $f(x) = 3x + 9$. If $f(x) = 0$, find $x$.
$3x+9=0 \Rightarrow x=-3$

Let $h(x) = 2x - 7$. Find $h(0)$.
$h(0) = -7$

6.
The graph of $f(x) = 3x - 1$ passes through the point $(2, 5)$. Without substituting: what is $f(2)$? If $f(x) = 8$, what is $x$?
$f(2) = 5$ (read the point). $f(x) = 8$: $3x-1=8 \Rightarrow x=3$.
