Factoring Techniques

College Algebra  ·  §4.1  ·  Instructor: Christopher Halverson  ·  Fall 2026

Core Ideas
Step 0 — Factor out the GCF first Always look for a common factor before anything else. e.g. $3x^2 - 12x = 3x(x - 4)$
Trinomial   $x^2 + bx + c$ Find two integers $p, q$ so that $pq = c$ and $p + q = b$. Then $x^2 + bx + c = (x + p)(x + q)$.
Special Patterns Difference of squares: $x^2 - a^2 = (x + a)(x - a)$    Perfect square: $x^2 \pm 2ax + a^2 = (x \pm a)^2$
