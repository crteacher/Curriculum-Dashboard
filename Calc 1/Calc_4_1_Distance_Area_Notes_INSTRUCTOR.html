Distance Traveled & Area Under a Curve

Calculus I  ·  §4.1  ·  Instructor: Christopher Halverson  ·  Fall 2026

A car's GPS logs its speed at several points during a trip — but the time intervals between readings aren’t equal. You have a table of speeds and times. How would you estimate the total distance traveled? Could you get a better estimate, and what would that require?
Area = Distance Traveled

When speed is constant:  distance = speed × time.
On a speed-time graph that’s the area of a rectangle: base = time, height = speed.

When speed varies: slice the time axis into small pieces. On each piece, speed barely changes — approximate it as constant and form a thin rectangle.

The total estimated distance = sum of all rectangle areas.
More (thinner) rectangles → better estimate.

▸ Why area equals distance

Suppose you drive at a steady 60 mph for 2 hours. Distance = 60 × 2 = 120 miles. On a speed-time graph, that’s a rectangle of height 60 and width 2 — area 120.

Now suppose your speed changes every hour: 40 mph the first hour, 70 mph the second. Total distance = 40(1) + 70(1) = 110 miles. That’s the sum of two rectangle areas.

The same logic extends to any number of pieces. The thinner the slices, the closer the sum of rectangle areas gets to the exact area under the speed-time curve — and therefore to the exact distance.

∴ area under speed-time curve = total distance traveled.

Left, Right, and Midpoint Estimates

Given a table of values, there are three natural choices for the height of each rectangle:

Left sum — use the value at the left edge of each interval.
Right sum — use the value at the right edge.
Midpoint sum — use the value at the center of each interval.

Width of each rectangle = difference between consecutive $x$- (or $t$-) values. Intervals do not need to be equal.

Estimate = $\sum (\text{height}) \times (\text{width})$ for each piece.

▸ Common Mistake

With unequal intervals, students often assume all widths are the same. They’re not — each width is the gap between that pair of consecutive $x$-values. Always subtract: width$_i$ = $x_{i+1} - x_i$.

Example: for $x = [0,\,3,\,5,\,8]$ the widths are $3,\,2,\,3$ — not $3,\,3,\,3$.

The midpoint sum often gives the most accurate estimate because it balances the overcount on one side of the true curve against the undercount on the other. All three converge to the same value as the number of rectangles grows.

Worked Examples
Example 1  —  Left sum from a table (equal intervals)

A car’s speed (mph) is recorded every hour:

t (hr)0123
v (mph)20302535

Estimate total distance using a left sum.

Three intervals, each width = 1 hr. Use left-endpoint speed:

$L = 20(1) + 30(1) + 25(1) = 75$ miles

Example 2  —  Right sum from the same table

Use the same speed data. Estimate using a right sum.

t (hr)0123
v (mph)20302535

Use right-endpoint speed for each interval:

$R = 30(1) + 25(1) + 35(1) = 90$ miles

Example 3  —  Midpoint sum from a table

Use the table below. Estimate distance on $[0, 4]$ with 2 subintervals of equal width, using a midpoint sum.

t (hr)01234
v (mph)3040503525

Two subintervals: $[0,2]$ and $[2,4]$, each width = 2.
Midpoint of $[0,2]$ is $t=1$; midpoint of $[2,4]$ is $t=3$.

$M = v(1)(2) + v(3)(2) = 40(2) + 35(2) = 80 + 70 = 150$ miles

Example 4  —  Left sum with unequal intervals

Speed is logged at uneven time intervals:

t (hr)0258
v (mph)40603050

Estimate total distance using a left sum.

Widths are unequal: $2 - 0 = 2$, $\;5 - 2 = 3$, $\;8 - 5 = 3$.

Use speed at left endpoint of each interval:

$L = 40(2) + 60(3) + 30(3) = 80 + 180 + 90 = 350$ miles

Practice Problems
1.

Use a left sum to estimate distance from the table:

t0359
v50704060
Widths: 3, 2, 4.   $L = 50(3)+70(2)+40(4) = 150+140+160 = 450$
2.

Use a right sum for the same table above.

Widths: 3, 2, 4.   $R = 70(3)+40(2)+60(4) = 210+80+240 = 530$
3.

Use a midpoint sum with 2 equal subintervals on $[0,4]$:

t01234
v2045605030
Subintervals $[0,2]$ and $[2,4]$, width 2 each. Midpoints $t=1$ and $t=3$.   $M = 45(2)+50(2) = 90+100 = 190$
4.
Find the left sum for $f(x) = 3x$ on $[0, 6]$ with $n = 3$.
$\Delta x = 2$; left points $0,2,4$.   $L = f(0)(2)+f(2)(2)+f(4)(2) = 0+12+24 = 36$
5.
If velocity is increasing throughout a trip, does the left sum overestimate or underestimate the actual distance? Explain briefly.
Underestimate — each rectangle uses the smallest speed in its interval (the left edge), so it falls short of the actual distance on that piece.
