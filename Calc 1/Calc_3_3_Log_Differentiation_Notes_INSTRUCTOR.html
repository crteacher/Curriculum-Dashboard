Logarithmic Differentiation

Calculus I  ·  §3.3  ·  Christopher Halverson  ·  Fall 2026  ·  INSTRUCTOR

You know $\dfrac{d}{dx}[x^5]=5x^4$ (power rule) and $\dfrac{d}{dx}[2^x]=2^x\ln 2$ (exponential rule). But what about $y=x^x$? The exponent isn't constant, so the power rule fails. The base isn't constant, so the exponential rule fails. How do you differentiate something like this?
General Log & Exponential Derivatives

Recall $\dfrac{d}{dx}[\ln x]=\dfrac{1}{x}$. For any base $b>0,\,b\neq 1$, use the change-of-base formula $\log_b x=\dfrac{\ln x}{\ln b}$:

$$\frac{d}{dx}[\log_b x]=\frac{1}{x\ln b}$$

With the chain rule (inner function $u$):

$$\frac{d}{dx}[\log_b u]=\frac{u'}{u\ln b}$$

Note: when $b=e$, $\ln e=1$ and the formula reduces to $\dfrac{1}{x}$, as expected.

General exponential derivative: write $b^x=e^{x\ln b}$ (since $e^{\ln b}=b$), then apply the chain rule with $u=x\ln b$, $u'=\ln b$:

$$\frac{d}{dx}[b^x]=e^{x\ln b}\cdot\ln b=b^x\ln b$$

With the chain rule (inner function $u$):

$$\frac{d}{dx}[b^u]=b^u\ln b\cdot u'$$

Note: when $b=e$, $\ln e=1$ and the formula reduces to $\dfrac{d}{dx}[e^x]=e^x$, as expected.

Quick examples:
$\dfrac{d}{dx}[\log_2 x]=\dfrac{1}{x\ln 2}$

$\dfrac{d}{dx}[\log_3(x^2+1)]=\dfrac{2x}{(x^2+1)\ln 3}$

$\dfrac{d}{dx}[5\cdot 3^x]=5\cdot 3^x\ln 3$

$\dfrac{d}{dx}[2^{x^2}]=2x\cdot 2^{x^2}\ln 2$

Logarithmic Differentiation

Use when $y=f(x)$ is a complicated product/quotient or has a variable exponent (like $x^x$).

  1. Take $\ln$ of both sides: $\ln y=\ln f(x)$
  2. Use log rules to expand the right side
  3. Differentiate both sides — left side gives $\dfrac{y'}{y}$ (chain rule on $\ln y$)
  4. Solve for $y'=y\cdot[\cdots]$
  5. Substitute back $y=f(x)$

Key log rules for step 2:
$\ln(AB)=\ln A+\ln B$
$\ln\!\left(\dfrac{A}{B}\right)=\ln A-\ln B$
$\ln(A^n)=n\ln A$

Worked Examples
Example 1  —  Chain rule with log base $b$
Differentiate $f(x)=\log_4(x^3-2x)$.
Use $\dfrac{d}{dx}[\log_b u]=\dfrac{u'}{u\ln b}$ with $u=x^3-2x$, $u'=3x^2-2$:
$$f'(x)=\frac{3x^2-2}{(x^3-2x)\ln 4}$$
Example 2  —  Product rule with log base $b$
Differentiate $g(x)=x^2\log_3 x$.
Product rule with $f=x^2$, $h=\log_3 x$:
$$g'(x)=2x\cdot\log_3 x+x^2\cdot\frac{1}{x\ln 3}=2x\log_3 x+\frac{x}{\ln 3}$$
Example 3  —  Logarithmic differentiation — variable exponent
Find $\dfrac{dy}{dx}$ for $y=x^x$.
Take $\ln$ of both sides: $\ln y=x\ln x$
Differentiate: $\dfrac{y'}{y}=\ln x+x\cdot\dfrac{1}{x}=\ln x+1$
Solve: $y'=y(\ln x+1)$
$$\frac{dy}{dx}=x^x(\ln x+1)$$
Example 4  —  Logarithmic differentiation — messy product
Find $\dfrac{dy}{dx}$ for $y=\dfrac{(x+1)^2(2x-1)^3}{\sqrt{x^2+1}}$.
Take $\ln$: $\ln y=2\ln(x+1)+3\ln(2x-1)-\tfrac{1}{2}\ln(x^2+1)$
Differentiate: $\dfrac{y'}{y}=\dfrac{2}{x+1}+\dfrac{6}{2x-1}-\dfrac{x}{x^2+1}$
$$\frac{dy}{dx}=\frac{(x+1)^2(2x-1)^3}{\sqrt{x^2+1}}\left(\frac{2}{x+1}+\frac{6}{2x-1}-\frac{x}{x^2+1}\right)$$
Example 5  —  Chain rule with exponential base $b$
Differentiate $f(x)=3^{x^2-1}$.
Use $\dfrac{d}{dx}[b^u]=b^u\ln b\cdot u'$ with $u=x^2-1$, $u'=2x$:
$$f'(x)=2x\cdot 3^{x^2-1}\ln 3$$
Practice Problems
1.
Find $\dfrac{d}{dx}[\log_5 x]$.
$\dfrac{1}{x\ln 5}$
2.
Find $\dfrac{d}{dx}[\log_2(x^4)]$.
Hint: simplify with log rules first.
$\log_2(x^4)=4\log_2 x$, so the derivative is $\dfrac{4}{x\ln 2}$
3.
Find $\dfrac{d}{dx}[x\cdot\log_{10} x]$.
Product rule: $\log_{10}x+x\cdot\dfrac{1}{x\ln 10}=\log_{10}x+\dfrac{1}{\ln 10}$
4.
Find $\dfrac{d}{dx}\!\left[\dfrac{\log_3 x}{x+1}\right]$.
Quotient rule: $\dfrac{\frac{1}{x\ln 3}(x+1)-\log_3 x}{(x+1)^2}$
5.
Find $\dfrac{dy}{dx}$ for $y=x^{2x}$.
$\ln y=2x\ln x$, so $\dfrac{y'}{y}=2\ln x+2$
$y'=x^{2x}\cdot 2(\ln x+1)$
6.
Find $\dfrac{dy}{dx}$ for $y=\dfrac{x^2(x+1)^3}{x-1}$.
$\ln y=2\ln x+3\ln(x+1)-\ln(x-1)$
$\dfrac{y'}{y}=\dfrac{2}{x}+\dfrac{3}{x+1}-\dfrac{1}{x-1}$
$y'=\dfrac{x^2(x+1)^3}{x-1}\!\left(\dfrac{2}{x}+\dfrac{3}{x+1}-\dfrac{1}{x-1}\right)$
7.
Find $\dfrac{d}{dx}[4^x]$.
$4^x\ln 4$
