Calculus I  ·  §4.7.2  ·  Christopher Halverson  ·  Fall 2026

How to use this practice The navy curve is the rate function \(f\). Sketch the accumulation function \(F(x) = \int_a^x f(t)\,dt\), which always starts at \(F(a) = 0\).
• Vertex (diamond) — place where \(F\) has slope 0 (where \(f = 0\): a max or min of \(F\))
• Key Point (circle) — place any other guiding point on the \(F\) curve
Problems 1–5: given \(f\), sketch \(F\).   Problem 6: stretch — given \(F\), sketch \(f\).
