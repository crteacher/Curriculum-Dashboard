Integral Notation & Geometric Area

Calculus I  ·  §4.1.5  ·  Christopher Halverson  ·  Fall 2026  ·  INSTRUCTOR

You’ve used areas of rectangles to estimate distances traveled. But what if the region under a curve IS a simple geometric shape? Before we build the full machinery of Riemann sums, let’s ask: which integrals can we read off from a picture right now, using only the geometry we learned before calculus?
Reading the Notation

$\displaystyle\int_{\,a}^{\,b} f(x)\,dx$

  • $\int$ — integral sign (elongated $S$, for “sum”)
  • $a$ — lower limit of integration
  • $b$ — upper limit of integration
  • $f(x)$ — integrand (the function being integrated)
  • $dx$ — variable of integration; think of it as the “width” direction

The result is a number: the signed area between the graph of $f$ and the $x$-axis, from $x=a$ to $x=b$.

Units: $\int_a^b f(x)\,dx$ has units equal to (units of $f$) × (units of $x$). If $f$ is in m/s and $x$ is in seconds, the integral is in meters.

Geometric Rules

These follow from what area means — no antiderivatives needed.

Constant Multiple:

$\displaystyle\int_a^b c\,f(x)\,dx = c\int_a^b f(x)\,dx$

Sum / Difference:

$\displaystyle\int_a^b [f\pm g]\,dx=\int_a^b f\,dx\pm\int_a^b g\,dx$

Zero-width interval: $\displaystyle\int_a^a f(x)\,dx=0$

Flip limits: $\displaystyle\int_b^a f(x)\,dx=-\int_a^b f(x)\,dx$

Interval split:

$\displaystyle\int_a^b f\,dx+\int_b^c f\,dx=\int_a^c f\,dx$

Signed Area

Area above the $x$-axis counts positive; area below counts negative. The definite integral adds up signed contributions across $[a,b]$ — so a region where $f(x) < 0$ subtracts from the total. This is not a flaw; signed area is exactly what makes the Net Change Theorem and FTC work cleanly. Flipping the limits of integration ($a \leftrightarrow b$) also negates the result, because you’re now sweeping right-to-left instead of left-to-right.

► Common Mistake

Students assume a definite integral is always positive because “area can’t be negative.” But $\int_a^b f(x)\,dx$ is signed area: a region below the $x$-axis contributes a negative quantity. For example, $\int_0^3(-2)\,dx=-6$ — the rectangle is entirely below the axis, so the answer is $-6$, not $6$.

If you need the total unsigned area, you must split at the zeros of $f$ and integrate $|f|$ on each piece separately. The plain definite integral will not do that for you automatically.

Worked Examples
Example 1  —  Rectangle
Evaluate $\displaystyle\int_0^4 3\,dx$ geometrically.
Rectangle: width 4, height 3
$\displaystyle\int_0^4 3\,dx = 4\times 3 = 12$
Example 2  —  Triangle
Evaluate $\displaystyle\int_0^4 x\,dx$ geometrically.
Right triangle: base 4, height 4
$\dfrac{1}{2}\cdot 4\cdot 4 = 8$
Example 3  —  Below the axis
Evaluate $\displaystyle\int_0^3 (-2)\,dx$ geometrically.
Rectangle below axis: area is negative
$3\times(-2) = -6$. The region is below the $x$-axis, so the integral is $-6$.
Example 4  —  Interval split
If $\displaystyle\int_0^3 f(x)\,dx = 5$ and $\displaystyle\int_3^7 f(x)\,dx = 9$, find $\displaystyle\int_0^7 f(x)\,dx$.
By the interval split rule:
$\displaystyle\int_0^7 f\,dx = \int_0^3 f\,dx + \int_3^7 f\,dx = 5+9 = 14$
Practice Problems
1.
Evaluate $\displaystyle\int_1^5 4\,dx$ geometrically.
Rectangle: width $=4$, height $=4$.   $4\times 4=16$
2.
Evaluate $\displaystyle\int_0^6 x\,dx$ geometrically.
Right triangle: base $=6$, height $=6$.   $\frac{1}{2}(6)(6)=18$
3.
Evaluate $\displaystyle\int_0^4(-3)\,dx$ geometrically. Is the result positive or negative?
$4\times(-3)=-12$. Negative — the function is below the $x$-axis.
4.
If $\displaystyle\int_0^5 f\,dx=8$ and $\displaystyle\int_5^8 f\,dx=-3$, find $\displaystyle\int_0^8 f\,dx$.
$8+(-3)=5$
5.
If $\displaystyle\int_2^9 f\,dx=11$, find $\displaystyle\int_9^2 f\,dx$.
$-11$. Flipping limits negates the integral.
6.
Use the constant multiple rule and geometry to evaluate $\displaystyle\int_0^3 2x\,dx$.
$2\displaystyle\int_0^3 x\,dx = 2\cdot\tfrac{1}{2}(3)(3)=9$
