L'Hopital's Rule

Calculus I  ·  §3.4.5  ·  Christopher Halverson  ·  Fall 2026  ·  STUDENT

As $x\to1$, both the numerator and denominator of $\dfrac{x^2+2x-3}{x-1}$ approach $0$ — you get the meaningless $\frac{0}{0}$. But the limit clearly exists (it's a removable hole). Is there one method that finds limits like this without needing a factoring trick every time?
L'Hopital's Rule

If $f(a)=g(a)=0$ (or both $\to\pm\infty$) and $f,g$ are differentiable near $a$, then

$$\lim_{x\to a}\dfrac{f(x)}{g(x)}=\lim_{x\to a}\dfrac{f'(x)}{g'(x)}$$

provided the right-hand limit exists. If the new limit is still $\frac{0}{0}$ or $\frac{\infty}{\infty}$, apply the rule again.

Recognizing When to Use It

Only apply L'Hopital's Rule to the indeterminate forms $\dfrac{0}{0}$ or $\dfrac{\infty}{\infty}$. Always check $f(a)$ and $g(a)$ first.

Other indeterminate forms ($0\cdot\infty$, $\infty-\infty$) must first be rewritten as a single fraction before the rule applies — e.g. $f\cdot g=\dfrac{f}{1/g}$.

▸ Why It Works — Local Linearization

Near $x=a$, the tangent line approximates each function: $f(x)\approx f(a)+f'(a)(x-a)$. Since $f(a)=0$, this simplifies to $f(x)\approx f'(a)(x-a)$. Likewise $g(x)\approx g'(a)(x-a)$.

So near $a$: $\dfrac{f(x)}{g(x)}\approx\dfrac{f'(a)(x-a)}{g'(a)(x-a)}=\dfrac{f'(a)}{g'(a)}$ — the $(x-a)$ factors cancel, leaving exactly the ratio of the tangent-line slopes.

As $x\to a$, the tangent-line approximation becomes exact, so the limit of $f/g$ really does equal $f'(a)/g'(a)$.

□
▸ Common Mistake

Students apply the quotient rule to $f/g$ instead of differentiating the numerator and denominator separately. L'Hopital's Rule uses $\dfrac{f'(x)}{g'(x)}$, not $\left(\dfrac{f(x)}{g(x)}\right)'$ — these are very different expressions.

Also common: applying the rule to a limit that isn't actually indeterminate. If $f(a)$ and $g(a)$ aren't both $0$ (or both $\pm\infty$), just substitute directly.

Worked Examples
Example 1  —  Classic $\frac{0}{0}$
Find $\displaystyle\lim_{x\to0}\dfrac{\sin x}{x}$.
Both $\to0$: indeterminate $\frac{0}{0}$.
$\displaystyle\lim_{x\to0}\dfrac{\sin x}{x}=\lim_{x\to0}\dfrac{\cos x}{1}=\cos(0)=1$
Example 2  —  Two ways to check
Find $\displaystyle\lim_{x\to1}\dfrac{x^2+2x-3}{x-1}$ — by factoring, and by L'Hopital's.
Factor: $\dfrac{(x+3)(x-1)}{x-1}=x+3\to4$.
L'Hopital: both $\to0$; $\displaystyle\lim_{x\to1}\dfrac{2x+2}{1}=4$. Same answer — good check!
Example 3  —  The $\frac{\infty}{\infty}$ form
Find $\displaystyle\lim_{x\to\infty}\dfrac{3^x}{x}$.
Both $\to\infty$: indeterminate $\frac{\infty}{\infty}$.
$\displaystyle\lim_{x\to\infty}\dfrac{3^x\ln3}{1}=\infty$ — the exponential still dominates; the limit diverges.
Example 4  —  Applying it twice
Find $\displaystyle\lim_{x\to\infty}\dfrac{3^x}{x^2}$.
Both $\to\infty$. First pass: $\displaystyle\lim_{x\to\infty}\dfrac{3^x\ln3}{2x}$ — still $\frac{\infty}{\infty}$!
Second pass: $\displaystyle\lim_{x\to\infty}\dfrac{3^x(\ln3)^2}{2}=\infty$
Practice Problems
1.
Find $\displaystyle\lim_{x\to0}\dfrac{e^x-1}{x}$.
Both $\to0$. $\displaystyle\lim_{x\to0}\dfrac{e^x}{1}=1$
2.
Find $\displaystyle\lim_{x\to2}\dfrac{x^2-4}{x-2}$.
Both $\to0$. $\displaystyle\lim_{x\to2}\dfrac{2x}{1}=4$
3.
Find $\displaystyle\lim_{x\to0}\dfrac{1-\cos x}{x^2}$.
Both $\to0$. First pass: $\dfrac{\sin x}{2x}$, still $\frac{0}{0}$. Second pass: $\dfrac{\cos x}{2}\to\dfrac{1}{2}$
4.
Find $\displaystyle\lim_{x\to\infty}\dfrac{\ln x}{x}$.
Both $\to\infty$. $\displaystyle\lim_{x\to\infty}\dfrac{1/x}{1}=\lim_{x\to\infty}\dfrac{1}{x}=0$
5.
Find $\displaystyle\lim_{x\to0^+}x\ln x$. (Rewrite the $0\cdot\infty$ form first!)
Rewrite: $\dfrac{\ln x}{1/x}$, now $\frac{\infty}{\infty}$ (as $x\to0^+$, $\ln x\to-\infty$).
$\displaystyle\lim_{x\to0^+}\dfrac{1/x}{-1/x^2}=\lim_{x\to0^+}(-x)=0$
6.
Find $\displaystyle\lim_{x\to\infty}\dfrac{x^2}{e^x}$.
Both $\to\infty$. Apply twice: $\dfrac{2x}{e^x}$ (still $\frac{\infty}{\infty}$), then $\dfrac{2}{e^x}\to0$
